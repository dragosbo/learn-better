Word cloud

Renders a word_cloud.json produced by code/make_wordcloud.py (run d.bat).

Which file do I load? Pick a *.word_cloud.json from the data/wordclouds/ folder (inside this repo, learn-better/data/wordclouds/). Each file is one video, named <video title> [<id>].word_cloud.json.
  • Don't see any files? Generate one first: run d (or python code\make_wordcloud.py) from the repo root. It reads a transcript and writes the JSON into data/wordclouds/.
  • Then click Browse below and open that folder, or use the server route in the note further down.
← browse to data/wordclouds/ and pick a *.word_cloud.json
How this works: the Python script writes only data (data/wordclouds/<base>.word_cloud.json). This page renders it client-side with wordcloud2.js (loaded from a CDN). Word size scales with frequency.
Opening from disk? Browsers block fetch() of a local file when you open this page via file://. Two options:
  1. Use the Load a JSON picker above (works offline, no server).
  2. Or serve the folder and pass ?file=:
    python -m http.server 8000 then open http://localhost:8000/wordcloud.html?file=data/wordclouds/<base>.word_cloud.json
