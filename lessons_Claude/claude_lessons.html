Build learn-better with an AI assistant

The Claude lesson series — a guided curriculum that walks a complete beginner (no AI-assistant experience, no existing Python project) from an empty folder to the full working repo: audio + transcript download, local Whisper transcription, summaries, word clouds, narrated audio, and deployment. You use an AI coding assistant as your primary tool throughout.

Rendered by Kiro, from Claude's lessons. This page is generated strictly from the Markdown files in lessons_Claude/ (built by Claude). Each lesson is framed by the kind of AI task it exercises (explanation, multi-file creation, debugging) and works with any AI assistant. Ten lessons, one focused session each (~30–150 min); each card links to the full lesson.

Closing the loop

By Lesson 10 you've reproduced the full learn-better repo — and practiced the workflow that got you there: framing requests, splitting explanation / creation / debugging AI tasks, iterating on real errors, and keeping the docs honest. The final lesson has the assistant update the docs and link the lessons.

Every lesson has a Re-orient the AI block (paste it after a restart or when the assistant loses context) and a When the AI misbehaves section with recovery steps for that lesson's likely snags.
