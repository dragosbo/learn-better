Overview

learn-better is a small toolkit for converting YouTube videos into study material. It downloads audio and transcripts, then feeds downstream steps like summarization, mind-maps, and Obsidian-based knowledge consolidation. The core downloader works without a Google API key by using yt-dlp.

Download audio

Grab audio (mp3 via ffmpeg) from a playlist, channel, or search.

Fetch transcripts

Save cleaned, timestamped transcripts per language (en/fr/ro).

Summarize

Turn transcripts into structured summaries using a reusable skill.

Learn

Roadmap toward speech-to-text, translation, TTS, and word clouds.

How it works (logic)

The recommended entry point, test_read_channel.py, runs three steps for each clip (capped at LIMIT, default 5). Files already on disk are skipped, so re-running only fetches what is missing.

Why yt-dlp everywhere? scrapetube silently returns zero videos (broken), and youtube-transcript-api hits empty-body errors on proxied networks. yt-dlp handles listing, subtitles, and audio with the same cookie / proxy / browser-impersonation options, so it is far more reliable.

Installation

Follow in order. The Python-version check (step 2) prevents the most common failure.

0. Prerequisites

  • Python 3.12 (3.10+ works). Do not use Python 3.7 (old Anaconda base).
  • One of: conda, Python 3.12 from python.org, or a Dev Container / Codespaces.
  • git to clone the repo.
git clone https://github.com/dragosbo/learn-better.git
cd learn-better

1. Create an isolated environment

conda (recommended):

conda create -n learn-better python=3.12 -y
conda activate learn-better

venv (Windows):

py -3.12 -m venv .venv
.venv\Scripts\activate

2. Verify the interpreter BEFORE installing

python --version   :: must print Python 3.12.x

3. Install dependencies

python -m pip install --upgrade pip
pip install -r requirements.txt

3b. Install ffmpeg (needed to convert audio to mp3)

ffmpeg is a system binary, not a pip package:

conda install -c conda-forge ffmpeg -y   :: recommended (into the conda env)
winget install ffmpeg                     :: Windows, system-wide
brew install ffmpeg                       :: macOS
sudo apt install ffmpeg                    :: Debian / Ubuntu

4. Verify the install

python -c "import youtube_transcript_api, yt_dlp, pandas, curl_cffi, ipykernel; print('all imports OK')"
No API key needed. Every active tool uses yt-dlp and works without a Google API key. The old API-key workflow (get_my_playlists.py) has been retired to the git-ignored ignore/ folder.

1. Local

Follow Installation (conda or venv), then run with the c/r/t/s batch files or python code/<script>.py.

2. Dev Container (VS Code + Docker)

The repo ships a .devcontainer/ on Python 3.12-bullseye that installs requirements.txt automatically and preloads the Python + Jupyter extensions.

  1. Install Docker and the VS Code Dev Containers extension.
  2. Open the repo and choose Reopen in Container.
  3. After the build, run directly (deps are already installed):
python code/test_read_channel.py
Add ffmpeg in the container with sudo apt install ffmpeg (or set AUDIO_FORMAT = None to skip mp3 conversion).

3. GitHub Codespaces (nothing to install)

Codespaces runs the same .devcontainer/ in the cloud.

  1. On the repo page: Code → Codespaces → Create codespace on main.
  2. Wait for the build (deps install automatically).
  3. In the terminal:
sudo apt install -y ffmpeg          # once, for mp3 conversion
python code/test_read_channel.py

4. Google Colab

No checkout by default, so clone inside a cell:

!git clone https://github.com/dragosbo/learn-better.git
%cd learn-better
!pip install -r requirements.txt
!apt-get -qq install -y ffmpeg
!python code/test_read_transcript.py
Cloud IPs hit the YouTube bot-check more often. If you see "Sign in to confirm you're not a bot", upload a cookies.txt and set COOKIES_FILE. Colab sessions are ephemeral, download audio/ / transcripts/ before disconnect or mount Google Drive.

Running the tools

Activate the environment, then use the helper batch files from the repo root:

CommandRunsWhat it does
cc.batActivate the learn-better conda env.
rtest_read_channel.pyAudio + transcripts for a playlist/channel/search.
ttest_read_transcript.pyTranscripts only, one file per language.
smake_summaries.pyList transcripts needing a summary; print AI instruction.

Configure the source at the top of the script (set ONE, leave the others None):

PLAYLIST_ID = "PLxxxxxxxx"          # a playlist
CHANNEL     = "@your_handle"        # or a channel (handle or UC... id)
SEARCH      = "some search terms"   # or a search
LIMIT       = 5                     # max clips to process
Bot-check ("Sign in to confirm you're not a bot"): export a cookies.txt while logged into YouTube and set COOKIES_FILE = "code/cookies.txt". That file is git-ignored.

Summaries workflow

Summaries are authored by the AI, not a script (a batch file cannot reason about content). s.bat does the deterministic prep and hands off to Kiro.

sequenceDiagram participant You participant s as s.bat / make_summaries.py participant Kiro as Kiro (AI) You->>s: run "s" s->>s: scan transcripts/*.en.txt s->>s: check summaries/ for matches s-->>You: list done vs. missing + paste-ready instruction You->>Kiro: paste instruction (apply skill_summary.md) Kiro->>Kiro: read each transcript Kiro-->>You: write summaries/*.summary.md

Typical flow for a new video: t (download transcript) → s (see what needs summarizing) → paste the instruction into Kiro. The format lives once in skill_summary.md (TOC, sections, strengths, weaknesses) and is reused for every video.

Troubleshooting

SymptomFix
No matching distribution found for yt-dlpYou are on Python < 3.10. Create/activate a 3.12 env; verify with python --version.
ModuleNotFoundError running a scriptWrong interpreter. Activate the env, re-run install.
ffmpeg not found / can't convert to mp3Install ffmpeg; open a new terminal; check ffmpeg -version. Or set AUDIO_FORMAT = None.
yt-dlp: Sign in to confirm you're not a botProvide cookies (COOKIES_FILE = "code/cookies.txt"); update yt-dlp with pip install -U yt-dlp.
NO TRANSCRIPT for a clipThat video has subtitles disabled. Whisper STT (roadmap) will cover these.
