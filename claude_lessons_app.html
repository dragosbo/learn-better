Lesson 01

First Contact

30–45 min ★☆☆☆☆ complexity AI tasks: Long-form explanation, Q&A, orientation
What You'll Build

Nothing tangible yet — by the end you know how to give an AI assistant useful instructions, get a coherent explanation of an unfamiliar tool, and what to do when the assistant loses its train of thought mid-session.

Key outcome: The re-orient pattern that every future lesson relies on.

Re-orient the AI 
I'm working through a guided curriculum to build a YouTube transcription and summarisation tool in Python, using an AI assistant as my primary coding tool. I'm on Lesson 01 — First Contact. We haven't created any files yet — this lesson is orientation only. Please continue from where I left off.
Concepts
The assistant is a collaborator, not a search engine
Give it context — what you're building, your OS, what already exists — rather than bare questions.
Prompts are repeatable
A well-structured prompt works consistently. This curriculum shows the optimised versions — prompts that worked after the project was actually built.
Context is fragile; recovery is cheap
Long sessions accumulate context. When the assistant drifts, paste a short re-orient block and pick up where you left off.

Step-by-step

01.1 Ask the assistant to explain an unfamiliar tool
Prompt
I'm planning to build a Python tool that downloads YouTube audio and transcripts for local processing. I've heard of yt-dlp, pytube, and scrapetube. Can you explain what each one does, why yt-dlp is now the preferred choice, and what its main advantages are over the others?
Please be concrete — mention specific things that broke or were retired.
Expected Output
yt-dlp is the actively-maintained successor. pytube breaks frequently with YouTube API changes. scrapetube broken since ~2025. yt-dlp handles audio, video, subtitles, format merging via ffmpeg, and bot-detection countermeasures. Mentions curl_cffi for TLS fingerprinting.
Verify
No command. Check the answer mentions: yt-dlp active maintenance, pytube fragility, why ffmpeg is needed alongside yt-dlp.
01.2 Understand what an AI assistant is good at
Prompt
I'm going to use you as my primary coding assistant to build a Python project from scratch. What kinds of tasks should I give you directly (where you work well without much hand-holding), and where should I be careful or verify your output? Give me practical examples for a Python project that uses yt-dlp, faster-whisper, and Piper TTS.
Expected Output
Good at: explaining concepts, generating boilerplate, config-driven scripts, project structure, documentation. Needs care: current package versions, OS-specific differences, very long agentic tasks.
Verify
Answer should mention verification — running the code, checking output files — not just trusting generated output blindly.
01.3 Learn the re-orient pattern
Prompt
I want to learn how to write a good "re-orient" block — a short paragraph I can paste at the start of a new chat session (or after a long break mid-session) to quickly restore your context about an ongoing project. What should such a block contain? Give me a template I can fill in for a Python CLI project.
Expected Output
Template covering: project name and purpose, current working file or milestone, OS and environment name, one sentence on where to continue.
Verify
Template covers: what the project does, what was just created, OS, env name, and where to pick up.
01.4 Practise crash recovery
Prompt
(Paste the re-orient block from the top of this lesson verbatim into a new session or fresh browser tab)
Expected Output
Assistant acknowledges context and asks what to do next or suggests starting Lesson 02. It should not ask you to repeat project details.
Verify
If the assistant responds as if it has context, the pattern works. If it asks clarifying questions, your re-orient block needs more detail.
When the AI Misbehaves
Very long answer when you asked for something brief
Add: "Keep your answer to 3–5 bullet points" or "Give me a one-paragraph summary first."
Assistant confidently states something wrong
Ask: "Are you sure? My understanding is that pytube is fragile because YouTube frequently changes its internal API. Can you confirm?"
Loses thread mid-session
Paste the re-orient block. If that doesn't help, start a fresh session. Sessions have finite context — earlier info silently drops out once it fills.

No new files created — orientation lesson.

Lesson 02

Project Scaffold

45–60 min ★★☆☆☆ complexity AI tasks: Project planning, multi-file creation, documentation generation
What You'll Build

An empty repo with a sound folder layout, .gitignore, a first README.md, a living plan.md, and the repo pushed to GitHub.

Key outcome: A committed, properly structured repo on GitHub — the foundation for every lesson that follows.

Re-orient the AI 
I'm working on the learn-better repo — a Python tool that downloads YouTube audio and transcripts, transcribes locally with faster-whisper, and generates summaries and word clouds. We're on Lesson 02 — Project Scaffold. No code files exist yet — we're creating the folder structure, .gitignore, README.md, and plan.md, then pushing to GitHub. OS: Windows. Please continue from [specific point].
Concepts
Give the AI a project vision, not a task list
Describe the full shape of what you're building upfront. The assistant makes better structural decisions than when you describe one file at a time.
Think step by step
Add "think step by step. List the files you will create before creating them." to multi-file prompts. Forces planning before acting — dramatically reduces half-finished sets of files.
The planning document belongs in the repo
A short plan.md recording decisions and reasoning is worth far more than chat notes. The assistant loses context between sessions; a committed plan file doesn't.

Step-by-step

02.1 Design the project structure
Prompt
I'm starting a Python CLI project. Here is what it will do:
- Download YouTube audio files and auto-generated transcripts using yt-dlp
- Transcribe audio locally with faster-whisper (no API, no cloud)
- Generate text summaries of transcripts using an AI API
- Build word clouds from transcripts
- Convert summaries to speech with Piper TTS
- Reencode audio to target bitrate
- All outputs go to a local data/ folder that is git-ignored

Think step by step. Before proposing a layout, list your assumptions. Then propose a folder structure with one-line descriptions of each folder. Do not create any files yet.
Expected Output
code/ — main scripts | lib/ — reusable helpers | scripts/ — one-letter runners (.bat + .sh) | data/ — all output (git-ignored) | config/ — JSON config files | docs/ — supplementary docs | notebooks/ — optional Jupyter
Verify
code/ and lib/ are separate. data/ is its own top-level folder. scripts/ is for runner shortcuts. If helpers and scripts are bundled, push back.
02.2 Create the folder structure
Prompt
Good. Now give me the exact shell commands to create this structure on Windows (Command Prompt). Use mkdir. Create empty placeholder files where useful so git tracks the folders. Show me one block of commands I can copy and paste.
Expected Output
mkdir code lib scripts data config docs notebooks
type nul > lib\__init__.py
type nul > code\.gitkeep
type nul > data\.gitkeep
Verify
Run `dir /b`. Check that code, lib, scripts, data, config, docs, notebooks all appear.
02.3 Create the .gitignore
Prompt
I'm working on Windows, but the project will also run on Linux inside a devcontainer. Generate a .gitignore for a Python project with: ignore entire data/ EXCEPT data/summaries/, standard Python artifacts, conda/venv folders, editor files, OS files. Output only the .gitignore content.
Expected Output
A .gitignore with a data/ ignore and a !data/summaries/ exception line. The exception line is critical — without it data/summaries/ gets ignored too.
Verify
Run: findstr /i "summaries" .gitignore
You should see !data/summaries/ (or similar).
02.4 Create the first README.md
Prompt
Write a README.md for this project named learn-better. Include: (1) one-paragraph description — what it does, no YouTube API needed, all transcription local; (2) Prerequisites — Python 3.12, conda, ffmpeg (system binary — NOT pip), yt-dlp, faster-whisper, Piper; (3) Quick Start with placeholder commands; (4) folder layout; (5) no badges, no emojis, no marketing tone.
Expected Output
Plain, readable README with five sections. Prerequisites explicitly calls out ffmpeg must be installed at OS level — NOT via pip.
Verify
Read Prerequisites. Confirms: Python 3.12, conda, ffmpeg as system binary (not pip), yt-dlp[default,curl-cffi]. If it says `pip install ffmpeg`, push back.
02.5 Create plan.md
Prompt
Create a plan.md — living planning document. Sections: ## Goal (one paragraph), ## Stack (table: Component | Tool | Why chosen), ## Open questions (three placeholder questions), ## Decisions log (empty). Output only the plan.md content.
Expected Output
Well-structured markdown with four sections. Stack table has yt-dlp for download, faster-whisper for transcription, Piper for TTS.
Verify
Open in markdown preview and confirm the table renders correctly.
02.6 Initialise git and push to GitHub
Prompt
I need to initialise a git repo, make a first commit, and push to a new GitHub repo named learn-better (public). Give me exact commands for Windows Command Prompt. Include: git init, set branch to main, add files, first commit, create GitHub repo with gh CLI, add remote, push.
Expected Output
git init | git checkout -b main | git add .gitignore README.md plan.md lib\__init__.py | git commit -m "initial scaffold" | gh repo create learn-better --public --source=. --remote=origin --push
Verify
git log --oneline — one commit. Visit github.com/[username]/learn-better and confirm files are there.
When the AI Misbehaves
Deeply nested folder structure
Push back: "I'd like to keep this flat. One level of subdirectories under the project root. Can you simplify?"
.gitignore exception for data/summaries/ missing or wrong syntax
Correct pattern: data/ on one line, then !data/summaries/ on the next. The ! must come after the data/ rule, not before. Show the two lines and ask it to explain why order matters.
README filled with emojis, badges, or marketing language
Add: "No badges, no emojis, no marketing tone. Plain GitHub markdown only."
gh repo create not available
Ask: "I don't have the GitHub CLI. How do I create the repo on GitHub.com and add the remote manually?"

Lesson 03

Environment Setup

45–60 min ★★☆☆☆ complexity AI tasks: Recommendation + reasoning, command generation, file creation
What You'll Build

A working Python 3.12 conda environment with all project dependencies installed, plus lib/paths.py — the file that tells every script where its outputs go.

Key outcome: lib/paths.py — the single source of truth for all output paths in the project.

Re-orient the AI 
I'm working on the learn-better repo. We're on Lesson 03 — Environment Setup. The repo already exists with .gitignore, README.md, and plan.md. We have NOT yet created the conda environment or any Python files. OS: Windows. Please continue from where I left off.
Concepts
ffmpeg is a system binary — not a Python package
Must be installed at OS level (conda-forge handles this cleanly). pip install ffmpeg installs a stub that does NOT include the binary — causes silent failures in yt-dlp and Whisper.
One constants file, one source of truth for paths
lib/paths.py defines every output folder as a named constant. Every script imports from it. Change one file, all scripts stay in sync.
Commit configuration, not data
requirements.txt and lib/paths.py are committed. data/ is git-ignored (except data/summaries/). Never commit audio, transcripts, or model weights.

Step-by-step

03.1 Ask for environment strategy
Prompt
I'm setting up a Python project on Windows. The project uses yt-dlp, faster-whisper, and Piper TTS. I need to decide between conda + pip, plain pip + venv, and uv. What are the trade-offs for this specific toolset? Pay special attention to ffmpeg, which some of these tools require as a system binary.
Expected Output
conda preferred — can install ffmpeg as real binary (no separate installer on Windows). Plain pip/venv cannot install ffmpeg. uv also cannot. For this project, conda + pip is the cleanest path on Windows.
Verify
Answer explicitly mentions that pip install ffmpeg installs a Python wrapper stub, NOT the real ffmpeg binary, and that this causes yt-dlp mp3 conversion to silently fail.
03.2 Create the conda environment
Prompt
Give me the exact conda commands to:
1. Create a new environment named learn-better with Python 3.12
2. Activate it
3. Install ffmpeg from conda-forge (not pip)
4. Verify ffmpeg is correctly installed
OS: Windows, Command Prompt.
Expected Output
conda create -n learn-better python=3.12 -y
conda activate learn-better
conda install -c conda-forge ffmpeg -y
ffmpeg -version
Verify
Run ffmpeg -version. You should see a version string like ffmpeg version 7.x.x. If not found, check you're in the learn-better env.
03.3 Understand why ffmpeg cannot use pip
Prompt
Why does `pip install ffmpeg` not work for a project that uses yt-dlp to download and convert audio? What actually happens when you run that command, and what should you do instead on Windows?
Expected Output
pip install ffmpeg installs a Python package with only Python bindings — NOT the actual C binary. yt-dlp invokes ffmpeg as subprocess.run(["ffmpeg", ...]). If the binary isn't on PATH, yt-dlp silently falls back to webm/m4a instead of mp3 with no clear error. Fix: conda install -c conda-forge ffmpeg.
Verify
No command. Key test is later when r.bat downloads audio — if output is .mp3 (not .m4a or .webm), ffmpeg is working.
03.4 Create requirements.txt
Prompt
Create requirements.txt with minimum-version pins (>=, not ==) for: youtube-transcript-api>=0.6,<1; yt-dlp[default,curl-cffi]>=2024.4.9; curl_cffi>=0.7; pandas>=2.0,<3; ipykernel>=6.29,<7; faster-whisper>=1.0; piper-tts>=1.2. Add a comment block noting ffmpeg is a SYSTEM DEPENDENCY. Do NOT include pytube or scrapetube.
Expected Output
A commented requirements.txt with 7 dependencies and a prominent comment block explaining the ffmpeg system dependency with conda-forge, winget, and apt install commands.
Verify
pip install -r requirements.txt (watch for errors; faster-whisper may download several hundred MB on first install — expected).
03.5 Smoke-test the environment
Prompt
Give me a short Python one-liner to verify that yt-dlp, faster-whisper, and curl_cffi all imported correctly in the learn-better environment.
Expected Output
python -c "import yt_dlp, faster_whisper, curl_cffi; print('All imports OK')"
Verify
Run with learn-better env active. You should see: All imports OK
03.6 Create lib/paths.py
Prompt
Create lib/paths.py defining output folder constants: DATA_DIR, AUDIO_DIR, AUDIO_REENCODED_DIR, TRANSCRIPT_DIR, GENERATED_TRANSCRIPT_DIR, WORDCLOUD_DIR, TTS_OUTPUT_DIR, SUMMARY_DIR. Use os.path.join(). Add a module docstring explaining this is the single source of truth. Note that data/summaries/ is the one exception that IS git-tracked.
Expected Output
Clean paths.py with 8 constants, docstring, and git-tracking note. Pattern: DATA_DIR = "data", AUDIO_DIR = os.path.join("data", "audio"), ...
Verify
python -c "from lib.paths import AUDIO_DIR, SUMMARY_DIR; print(AUDIO_DIR, SUMMARY_DIR)"
Expected: data\audio data\summaries
When the AI Misbehaves
Assistant suggests pip install ffmpeg or pip install ffmpeg-python
Push back: "These are Python packages that wrap ffmpeg — they don't install the binary itself. Can you show me the conda-forge install command?"
pip install fails on faster-whisper or CTranslate2
Ask: "pip is failing to install faster-whisper on Windows x86-64 Python 3.12. Is there a pre-built wheel? Usually pip install faster-whisper --prefer-binary resolves it."
Assistant pins versions with == instead of >=
Ask: "Can you use minimum-version pins (>=) instead of exact pins? This is a development project."

Lesson 04

First Working Script

60–90 min ★★★☆☆ complexity AI tasks: Multi-file creation, config design, debugging from an error message
What You'll Build

code/list_playlists.py — a script that lists a channel's public playlists and saves them to data/playlists.json, plus runner pair scripts/p.bat and scripts/p.sh.

Key outcome: The full debug cycle: paste error → understand it → fix it → re-run. A skill used in every lesson after this.

Re-orient the AI 
I'm working on the learn-better repo. We're on Lesson 04 — First Working Script. The environment is set up (learn-better conda env, Python 3.12, ffmpeg, all packages). The last files we created were requirements.txt and lib/paths.py. We have NOT yet written any scripts in code/ or scripts/. OS: Windows. Conda env: learn-better.
Concepts
Config at the top of the file
All tunable parameters live in a clearly-marked all-caps config block at the top — not buried in function bodies. Easy to scan and change without reading the implementation.
Feed the actual error message back
When a script fails, copy-paste the full traceback. Never paraphrase. The exact error text (exception type, file name, line number) is what the assistant uses to diagnose.
Ask for diagnosis before asking for a patch
After pasting an error, ask "what does this error mean?" before "how do I fix it?" You learn more and can catch symptom-not-cause fixes.

Step-by-step

04.1 Discuss the script's purpose and design
Prompt
I want to write a Python script called code/list_playlists.py. Its job:
- Accept a YouTube channel handle (@handle) or URL as a config variable
- List all public playlists for that channel using yt-dlp
- Optionally list videos inside each playlist, up to VIDEO_LIMIT per playlist
- Count total videos per playlist (optional, controlled by a flag)
- Save result as JSON to data/playlists.json

The project has lib/paths.py. lib/net.py and lib/youtube.py are not written yet — stub them.

Tell me: what config variables will this script need at the top, and what should the JSON output structure look like? Think step by step. Do not write code yet.
Expected Output
Config: CHANNEL, LIST_VIDEOS_FOR, VIDEO_LIMIT, COUNT_VIDEOS. JSON: list of objects with id, title, url, video_count, videos[].
Verify
Config block has at least CHANNEL, VIDEO_LIMIT, COUNT_VIDEOS. If LIST_VIDEOS_FOR is missing, ask for it — it controls which playlists get expanded.
04.2 Generate the script and runners
Prompt
Now write code/list_playlists.py with config block at top (CHANNEL, LIST_VIDEOS_FOR, VIDEO_LIMIT, COUNT_VIDEOS), imports (os, json, lib.net, lib.youtube, lib.paths.DATA_DIR), and logic that: calls net.apply_no_proxy_env() first, fetches playlists, optionally fetches videos, writes JSON with json.dump. Also write scripts/p.bat and scripts/p.sh.
Expected Output
Three files. list_playlists.py with config at top and net.apply_no_proxy_env() called before any network work. p.bat: call conda activate learn-better / python code\list_playlists.py. p.sh: shebang + activate + python code/list_playlists.py.
Verify
from lib import net, youtube is present. net.apply_no_proxy_env() appears before any yt-dlp call. Output path uses os.path.join(DATA_DIR, "playlists.json").
04.3 Save files and first run
Prompt
(Run: python code\list_playlists.py after setting CHANNEL to a real handle)
Expected Output
Either: success (playlists.json created) | ImportError on lib.net or lib.youtube (stubs missing) | Other error — proceed to debug cycle.
Verify
data/playlists.json exists with at least one playlist entry. Valid JSON (VS Code highlights syntax errors).
04.4 Iterate and fix — the debug cycle
Prompt
I ran code/list_playlists.py and got this error:

[paste the full traceback here — every line]

What does this error mean? What is the most likely cause?
Expected Output
Assistant identifies error type and explains it in plain terms. For ImportError on lib.net, it explains the module doesn't exist yet and offers to create a stub.
Verify
After fix, re-run and copy-paste any new error. Repeat until script runs cleanly.
When the AI Misbehaves
Hardcodes output path instead of using DATA_DIR
Push back: "The project uses lib/paths.py as the single source of truth. Can you change to os.path.join(DATA_DIR, 'playlists.json')?"
Script runs but playlists.json contains empty list []
Two causes: (1) wrong channel handle — verify it in browser; (2) channel has no public playlists.
403 or 429 HTTP error
YouTube rate-limits unauthenticated requests. Wait a few minutes and retry. lib/net.py (Lesson 09) has COOKIES_FROM_BROWSER option.
p.bat uses python3 instead of python
On Windows with conda, correct command is python. Push back: "On Windows with conda, the command is python, not python3."

Lesson 05

Audio and Transcripts

75–90 min ★★★☆☆ complexity AI tasks: Multi-file creation, config design, format options reasoning
What You'll Build

code/read_channel.py (audio download) and code/read_transcript.py (caption download), a first config/config_transcribe.json, and runner shortcuts r.bat/r.sh and t.bat/t.sh.

Key outcome: Two download modes kept deliberately separate: audio (large, slow) and captions (free, fast). You often need one without the other.

Re-orient the AI 
I'm working on the learn-better repo. We're on Lesson 05 — Audio and Transcripts. Files so far: lib/paths.py, lib/net.py (stub), code/list_playlists.py, scripts/p.bat, scripts/p.sh. We have NOT yet written read_channel.py, read_transcript.py, or any config files. OS: Windows. Conda env: learn-better.
Concepts
Two download modes, two scripts
Audio download (read_channel.py) and caption download (read_transcript.py) are deliberately separate. Transcripts are free and fast; audio is large and slow.
Selection by playlist, channel URL, or search
Both scripts support three input modes — playlist ID, channel handle, or search string. Only one needs to be non-empty. Priority: PLAYLIST_ID → CHANNEL → SEARCH.
Config files extend top-of-file defaults
Top-of-file variables are the defaults. If a JSON config file is passed or exists at a well-known path, it overrides those defaults. Cleaner than editing the Python file each time.

Step-by-step

05.1 Discuss the two-script design
Prompt
I want to write two scripts: read_channel.py (downloads audio) and read_transcript.py (downloads captions). Both support three selection modes: playlist ID, channel handle, or search query. Both call lib.net.apply_no_proxy_env() before any network calls. Before writing code: list the config variables each script needs, and explain the selection priority.
Expected Output
read_channel.py config: PLAYLIST_ID, CHANNEL, SEARCH, LIMIT, DOWNLOAD, AUDIO_FORMAT, AUDIO_QUALITY. read_transcript.py config: PLAYLIST_ID, CHANNEL, SEARCH, LIMIT. Priority: PLAYLIST_ID → CHANNEL → SEARCH.
Verify
Both configs include all four selection variables. If LIMIT is missing, push back — without it a channel query fetches every video.
05.2 Generate code/read_channel.py
Prompt
Write code/read_channel.py with config block (PLAYLIST_ID, CHANNEL, SEARCH, LIMIT, DOWNLOAD, AUDIO_FORMAT="mp3", AUDIO_QUALITY="192"), imports including AUDIO_DIR from lib.paths, and logic: net.apply_no_proxy_env() first, build URL, list videos, download if DOWNLOAD=True. Use AUDIO_DIR from lib.paths — do not hardcode the path.
Expected Output
Clean script matching spec. Config at top, net.apply_no_proxy_env() as first executable line, AUDIO_DIR used throughout.
Verify
from lib.paths import AUDIO_DIR (not DATA_DIR). net.apply_no_proxy_env() before any yt-dlp call. DOWNLOAD=True controls dry-run.
05.3 Generate code/read_transcript.py
Prompt
Write code/read_transcript.py with config block (PLAYLIST_ID, CHANNEL, SEARCH, LIMIT), import TRANSCRIPT_DIR from lib.paths, and logic: net.apply_no_proxy_env() first, build URL, list videos, call youtube.download_transcript with languages from textutil.load_languages() — do not hardcode ["en","fr","ro"].
Expected Output
Mirrors read_channel.py structure but uses TRANSCRIPT_DIR and calls download_transcript. Languages come from textutil.load_languages().
Verify
from lib.paths import TRANSCRIPT_DIR. Languages loaded via textutil.load_languages(), not hardcoded. net.apply_no_proxy_env() is first.
05.4 Generate runner pairs
Prompt
Write runner shortcut files: scripts/r.bat + r.sh for read_channel.py, scripts/t.bat + t.sh for read_transcript.py. .bat pattern: call conda activate learn-better / python code\<script>.py. .sh pattern: #!/usr/bin/env bash / conda activate / python.
Expected Output
Four files. .bat files use 'call conda activate' (not just 'conda activate') — call is required or the script exits immediately after conda returns.
Verify
Open scripts/r.bat. Confirm it has 'call conda activate' (not just 'conda activate'). Missing call is a common .bat mistake.
05.5 Create config/config_transcribe.json
Prompt
Create config/config_transcribe.json with keys matching read_transcript.py config: playlist_id, channel, search, limit. Output only valid JSON — JSON doesn't support comments.
Expected Output
Valid JSON with four keys: {"playlist_id": "", "channel": "@handle", "search": "", "limit": 10}
Verify
python -c "import json; json.load(open('config/config_transcribe.json')); print('valid JSON')"
When the AI Misbehaves
Hardcodes ["en","fr","ro"] instead of textutil.load_languages()
Push back: "Language list should come from textutil.load_languages(), not hardcoded. Later the user configures it in code/languages.json."
.bat file missing 'call' before conda activate
In .bat files, conda activate is itself a script. Without call, the parent script exits after conda finishes and python never runs.
download_transcript silently writes nothing
Not all channels have auto-generated captions. Ask: "What flag does yt-dlp use to list available subtitle tracks?" (Answer: yt-dlp --list-subs <url>)

Lesson 06

Whisper Transcription

75–90 min ★★★★☆ complexity AI tasks: Config design, multi-file creation, import order reasoning
